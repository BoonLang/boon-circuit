# Breakage census, measured (review M1, 2026-09-30)

Not authority. These are scanner estimates that check the plan's §5.1 table
(`docs/plans/BOON_COMPILER_REWRITE_PLAN.md:741-770`). The real census is still
the new checker's own output.

- **Script:** `census.py`. It is a token-level scanner with bracket matching,
  item splitting, lexical scopes and FUNCTION call resolution. Run it with
  `python3 census.py`; it takes about 16 s.
- **Output:** `census_results.json` (every site, with file and line; 2.8 MB,
  regenerated by the script and kept outside the repository) and
  `sample40_classified.json` (the hand-classified WHEN→WHILE sample).
- **Corpus.** The scanner reads three kinds of source:
  - the 177 files from `git ls-files "*.bn"` (31,233 lines);
  - 1 Boon source embedded as a string in a `.bn` file
    (persons_pro `Templates/ProfilePage.bn:2`);
  - 191 Boon-like string literals in 48 tracked Rust files (3,690 lines). A
    literal counts as Boon-like when it contains at least 2 Boon markers.
- **Reporting.** The first number is always `.bn` files only. `+R` is the
  number inside Rust strings.

## WHEN → WHILE heuristic (D30)

A WHEN counts as a candidate when all of these hold:
1. Its selector is not event-like. Event-like means the selector contains THEN,
   an `events`/`event` segment, a known event name (press, click, key_down,
   change, blur, focus, …), or a `SOURCE` key declared in the same unit.
   Effect-result selectors, meaning effect module calls or names ending in
   `_result`, `_response` or `_page`, are counted separately.
2. It is not inside a copy context: a THEN body, or an arm of an event WHEN.
3. Some arm reads something that can update on its own. That is either
   - a free name or path other than the arm's binders, local binders, local
     record or BLOCK keys, tags and literals, or
   - a call to a user FUNCTION that reads `PASSED` (transitively; in practice,
     theme and view helpers).
4. The **refined** rule also drops reads whose root the selector itself reads.
   A derived selector fires whenever one of its inputs fires (D32), so those
   copies are never stale.

Roles:
- **theme:** the file name contains "theme", or it is one of the 5 TodoMVC
  theme modules;
- **view:** a FUNCTION that contains Element/Scene/Document, plus every
  non-stateful function it calls, transitively;
- **state:** everything else.

**Where the heuristic misses:**
- calls that do not resolve (a bare name defined in another file);
- FUNCTION parameters that are bound to constants at every call site. The
  scanner found 27 such WHENs.
- the 27 WHENs whose selector is an effect result, which need a person to
  judge;
- WHENs nested inside the arms of a candidate.

Taking these into account, the estimated D30 migration is **300-360 `.bn`
sites**. Today's runtime already evaluates WHEN live, so switching these sites
to WHILE keeps today's behaviour.
