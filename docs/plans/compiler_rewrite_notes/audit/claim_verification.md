===== C2-call-path-not-semantic partially_confirmed
SUMMARY: The numbers check out, and so does the structural point. The kernel compiles call paths, not call sites: each of the 155 principals compiles its whole call tree, and every frame compiles its own callees again. InvocationKey keys on the caller's TypeVariableIds and ModeVariableIds. Only per-definition and per-syntactic-call outputs are published. The central semantic claim is wrong as stated, though. A call's result does not depend only on (callee, SpecializationKey = static tag sets + initial_state_surface) plus the actual types. It also depends on per-actual flags that are not type facts: compile-time authority, the guarded bit and the requirement_backflow bit. Through PASSED/inherited formals these flags come from the grandparent's actual variable.
